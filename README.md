# drawio 存储仓库

本仓库用于存储和管理 drawio 格式的图表文件。请将您的 drawio 文件上传至本仓库，以便团队成员共享和协作。

## 使用说明

1. 将 `.drawio` 文件添加/上传到本仓库相应目录下。
2. 如有需要，可新建文件夹以便分类管理不同类型的图表。

## 目录结构示例

```
/your-diagrams
  ├─ example1.drawio
  └─ example2.drawio
```

## 说明

- 本仓库仅作为 drawio 文件的集中存储地，不涉及图表编辑功能。
- 建议通过 [draw.io 官网](https://app.diagrams.net/) 或相关客户端编辑后上传。
